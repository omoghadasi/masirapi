چرا Masirapi؟

همه‌چیز برای یک اتصال بی‌دردسر

از اولین درخواست تا مدیریت مصرف در مقیاس بالا؛ بدون درگیرشدن با حساب‌ها و صورت‌حساب‌های پراکنده.

یک درگاه، همهٔ ارائه‌دهندگان

به‌جای ساختن حساب‌های متعدد، مدل‌های متن‌باز و تجاری بیش از ۴۰ ارائه‌دهنده را از یک رابط واحد صدا بزنید.

سازگار با OpenAI

کد فعلی‌تان را نگه دارید؛ فقط Base URL و کلید API را عوض کنید. SDKها و ابزارهای آشنا همان‌طور کار می‌کنند.

قیمت‌گذاری شفاف تومانی

هزینهٔ هر مدل مشخص و به تومان است؛ بدون نرخ‌های پنهان، با گزارش دقیق هزینهٔ هر درخواست.

کنترل کامل مصرف

داشبورد مصرف، گزارش هزینه‌ها و تعیین سهمیه برای هر کلید؛ همه‌چیز در یک نگاه، بدون غافلگیری.

کلیدهای مستقل و امن

برای هر پروژه یک کلید جدا بسازید، محدودیت مصرف تعیین کنید و هر زمان خواستید آن را ابطال کنید.

پشتیبانی فارسی

تیم فارسی‌زبان، مستندات روشن و کانال فعال برای پاسخ به سؤال‌ها و اطلاع‌رسانی تغییرات.

شروع کار

در سه قدم متصل شوید

کمتر از پنج دقیقه تا اولین درخواست؛ با همان ابزارها و SDKهایی که امروز استفاده می‌کنید.

  1. ۱

    ثبت‌نام کنید

    در masirapi.ir یک حساب بسازید؛ کمتر از یک دقیقه طول می‌کشد.

  2. ۲

    کلید API بسازید

    از بخش «کلیدهای API» در داشبورد، یک کلید جدید بسازید و سهمیهٔ مصرفش را تعیین کنید.

  3. ۳

    متصل شوید

    آدرس پایه را روی https://masirapi.ir/v1 بگذارید و با همان SDK همیشگی درخواست بفرستید.

نکتهٔ امنیتی: کلید API را فقط در سرور نگه دارید؛ هرگز آن را در کد سمت کاربر یا مخزن عمومی قرار ندهید. 

from openai import OpenAI

client = OpenAI(
    api_key="MASIRAPI_API_KEY",
    base_url="https://masirapi.ir/v1",
)

resp = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "سلام!"}],
)
print(resp.choices[0].message.content)
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.MASIRAPI_API_KEY,
  baseURL: "https://masirapi.ir/v1",
});

const resp = await client.chat.completions.create({
  model: "gpt-4o",
  messages: [{ role: "user", content: "سلام!" }],
});
console.log(resp.choices[0].message.content);
curl https://masirapi.ir/v1/chat/completions \
  -H "Authorization: Bearer $MASIRAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "messages": [{"role": "user", "content": "سلام!"}]
  }'

فقط دو خط مشخص‌شده را با کلید و آدرس Masirapi جایگزین کنید؛ بقیهٔ کد دست‌نخورده می‌ماند.

سؤال‌های پرتکرار

آیا باید کدم را تغییر بدهم؟

خیر. Masirapi با فرمت OpenAI سازگار است؛ کافی است Base URL و کلید API را در همان SDK یا ابزار فعلی جایگزین کنید. درخواست‌ها و پاسخ‌ها با همان ساختار آشنای قبلی ردوبدل می‌شوند.

هزینه‌ها چگونه محاسبه می‌شود؟

بر اساس مصرف واقعی هر درخواست و قیمت اعلام‌شدهٔ همان مدل، به تومان. قیمت هر مدل پیش از استفاده مشخص است و گزارش دقیق هر درخواست در داشبورد مصرف قابل مشاهده است.

اگر یک ارائه‌دهنده در دسترس نباشد چه؟

درخواست‌ها میان کانال‌های جایگزین مسیریابی می‌شوند تا سرویس شما پایدار بماند؛ بدون اینکه تغییری در سمت شما لازم باشد.

اخبار مدل‌ها و قیمت‌ها را از کجا دنبال کنم؟
